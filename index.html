Power BI Transactions Dashboard (Uzbekistan, 2024–2025)

Personal project • Data cleaning, modeling & visualization

DAX

Situation: I wanted a real-world dataset to strengthen my skills in data cleaning, modeling, and visualization.

Task: Build an interactive Power BI dashboard using Uzbekistan transaction data (2024–2025) with clear KPIs, slicers, and insight-focused visuals.

Action: Cleaned and transformed raw CSV data for consistency, created DAX measures (Total Amount, Total Transactions, Average Amount), and built a dashboard with slicers (Region, Year, Transaction Type) and visuals for monthly trends, region comparisons, transaction-type distribution, and top customers.

Result: Delivered a decision-ready dashboard highlighting Total Amount (5M), Total Transactions (7), and Average Amount (707.14K), improving my ability to turn raw data into actionable insights and communicate findings effectively.

Tech Stack
  • Power BI (interactive report design)
  • Power Query (data preparation)

  • CSV (transaction dataset)
